# Slice 37 — iOS Hardening & App Store Readiness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make QuickServe production-ready on iOS at parity with Android — inspection-provable config/code hardening plus a permanent App Store readiness checklist — without new features, workflow changes, or Android regressions.

**Architecture:** Audit-first hardening. Task 1 corrects `app.json`/`eas.json` iOS config (splash, associated-domains scaffold) and adds a static invariant test. Task 2 audits all 8 iOS capabilities and locks them with an invariant test. Task 3 makes only inspection-provable code changes (extract a pure maps helper; audit upload/safe-area/keyboard/status-bar and document rather than speculatively edit). Tasks 4–5 are documentation + verification. No schema, no backend, no business-logic changes.

**Tech Stack:** Expo React Native (SDK ~56), Expo Router, TypeScript, Jest, EAS. Config in `app.json`/`eas.json`. Static tests read files via `fs` (no device/DB).

## Global Constraints

- **Inspection-only:** correct only issues that are **statically provable from inspection**. Never "fix iOS issues" on suspicion.
- **Implementation guardrail:** if a proposed code change cannot be proven necessary by static inspection, **document it in the iOS Readiness Checklist instead of modifying production code**.
- **No new dependencies** without stopping and reporting to the human first.
- **No Android behavior change / no Android regression.** The maps helper must preserve the existing Android `google.navigation:q=` branch exactly.
- No new customer/provider/admin features. No booking / dispatch / payment / auth / provider-workflow / analytics / ranking / payout logic changes. No schema/migration changes. No AI.
- No fabricated credentials/IDs: `extra.eas.projectId` and Sentry `organization`/`project` stay empty → checklist TODOs.
- Associated-domains scaffold is **inert** (placeholder domain); `quickserve://` remains the only active deep-link mechanism. No route/tab/stack/deep-link changes.
- No App Store submission this slice.
- Baseline test count at branch start: **2852** (Slice 36 head). Suite must stay green with no weakened assertions.
- Gate per task: `npm test`, `npx tsc --noEmit`, `npx expo export --platform web`, `npx expo export --platform android`. (Run `npx expo export --platform android` before `tsc` if route types drift.)

```ts
let raw: string;

  raw = fs.readFileSync(APP_JSON, 'utf-8');

/** Finds a plugin's options object by plugin name (plugins are string | [name, opts]). */
function pluginOpts(name: string): any {
  const entry = (expo.plugins as any[]).find(
    (p) => p === name || (Array.isArray(p) && p[0] === name),
  );
  if (!entry) return undefined;
  return Array.isArray(entry) ? entry[1] : {};
```

```ts
// maps.ts — builds a platform-appropriate turn-by-turn directions URL.
import { Platform } from 'react-native';

/**
 * Returns a directions URL to (lat, lng):
 *   iOS      → Apple Maps (https)
 *   Android  → Google Maps turn-by-turn intent (unchanged from prior behavior)
 *   other    → Google Maps directions web URL
 */
export function buildDirectionsUrl(lat: number, lng: number): string {
  return Platform.select({
    ios: `https://maps.apple.com/?daddr=${lat},${lng}`,
    android: `google.navigation:q=${lat},${lng}`,
    default: `https://www.google.com/maps/dir/?api=1&destination=${lat},${lng}`,
  }) as string;
}
```
